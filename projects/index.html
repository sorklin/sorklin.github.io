House rules

How this lot is put together.

  • Static first. Pages on GitHub Pages. If a project needs a server, that's a decision I have to defend.
  • Your data stays put. Local-first storage — IndexedDB or a file you own. Nothing leaves the browser unless you point it at something.
  • Models on my hardware. Self-hosted by default. Someone else's pricing page shouldn't be a dependency.
  • Big binaries live elsewhere. The 56 MB emulator core ships from a separate repo so this site stays a git clone away, not a wait.
