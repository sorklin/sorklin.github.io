Emulator log / diagnostics
ROM set rthunder (Rolling Thunder rev 3) — 28 files, each verified against MAME's ROM_START(rthunder) by size and CRC32. The emulator core and all assets are served from this folder, so the page runs offline. One sound MCU (hd637a01x0p.e3) has never been dumped, so a few PCM effects may be missing — that is a limitation of the dump, not of this build.
